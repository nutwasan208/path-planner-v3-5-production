# Phase 3 — ระบบวิเคราะห์และรายงานประเมินผู้เรียน

Phase 3 รวมความสามารถของ Phase 1 และ Phase 2 ทั้งหมด และเพิ่มระบบวิเคราะห์เพื่อช่วยครูประเมินผู้เรียน

## ความสามารถใหม่

- สรุปผลอัตโนมัติเป็นข้อความภาษาไทยตามตัวกรองปัจจุบัน
- ระบุด่านที่ยากที่สุดจากเวลา อัตราผ่าน ข้อผิดพลาด และการใช้คำใบ้
- ระบุนักเรียนที่ควรได้รับการช่วยเหลือ โดยใช้เกณฑ์ที่ครูตั้งค่าได้
- แสดงพัฒนาการระหว่างรอบแรกและรอบล่าสุดของนักเรียน
- แบ่งกลุ่มผลประเมินเป็น ดีมาก / ดี / ควรฝึกเพิ่ม / ควรช่วยเหลือ
- พิมพ์หรือบันทึกรายงานเป็น PDF ผ่านคำสั่ง Print ของเบราว์เซอร์
- ส่งออกรายชื่อนักเรียนที่ควรติดตามเป็น CSV
- รองรับหลายเกมใน Dashboard เดิมผ่านตัวกรองเกม

## ลำดับ SQL สำหรับติดตั้งใหม่

1. `supabase/phase1_schema.sql`
2. `supabase/phase2_migration.sql`
3. `supabase/phase3_migration.sql`

## เกณฑ์เริ่มต้น

- เวลาช้าต่อด่าน: 90 วินาที
- ตอบผิดมาก: 3 ครั้งต่อผลด่าน
- ใช้คำใบ้มาก: 2 ครั้งต่อผลด่าน
- ความคืบหน้าขั้นต่ำ: 60%

ครูสามารถแก้เกณฑ์จากหน้า Dashboard และบันทึกลง Supabase ได้
